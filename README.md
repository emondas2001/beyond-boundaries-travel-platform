# Beyond Boundaries

**Beyond Boundaries** is a comprehensive web platform designed for tourists and travelers. It helps users explore destinations, book hotels, hire guides, visit restaurants, rent vehicles, and access essential services like hospitals — all from a single platform. The goal is to simplify travel planning and make trips more enjoyable and organized.

---

## Project Overview

The platform provides the following functionalities:

- **User Authentication**
  - Secure registration and login system.
  - User session management with logout functionality.

- **Dashboard**
  - Personalized user dashboard to manage bookings and preferences.

- **Explore Places**
  - Discover tourist destinations with descriptions and categories.
  - Save favorite places to a wishlist.

- **Hotel Booking Module**
  - View hotels, check room availability and prices.
  - Book rooms with check-in and check-out dates.
  - Calculate total price based on room and duration.

- **Guides**
  - View details of local guides including ratings, experience, and price.
  - Option to hire guides for trips.

- **Restaurants**
  - Find restaurants, view menus, food prices, and place orders.

- **Vehicles**
  - Book or rent cars, bikes, buses, jeeps.
  - View driver details, experience, and ratings.

- **Hospitals**
  - Suggest nearby hospitals.
  - Book doctor appointments and access ambulance information.

- **Settings, About, and Contact**
  - Update user profile, learn about the platform, and view contact info.

## Technology Stack

- **Frontend:** HTML5, CSS3 (Bootstrap), JavaScript, AJAX  
- **Backend:** PHP

## Future Goals

The platform is designed to grow into a full-featured travel solution. Planned enhancements include:

1. **Ratings & Reviews System**
   - Allow users to review hotels, guides, restaurants, vehicles, and tourist places.

2. **Trip Planner Module**
   - Users can plan trips including destinations, hotels, guides, and vehicles for selected dates.

3. **Payment Integration**
   - Implement online payment for hotel, restaurant, and vehicle bookings.

4. **Notifications & Reminders**
   - Alerts for bookings, appointments, and upcoming trips.

5. **Weather & Travel Advisory**
   - Display weather information for selected destinations.

6. **Admin / Business Panel**
   - Enable service providers (hotels, restaurants, guides) to manage listings.

7. **Multi-language Support**
   - Expand accessibility for international users.

8. **Map Integration**
   - Embed location maps for hotels, restaurants, hospitals, and tourist spots.
